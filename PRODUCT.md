# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

1. **Lead Game Designers & Technical Directors**: Looking for demonstrated systems architecture, Unreal Engine 5 mastery, C++ gameplay mechanics, and technical problem-solving.
2. **Studio Recruiters & Talent Partners**: Conducting rapid 30-to-60-second evaluations on desktop and mobile, needing immediate proof of competence, playable demos, and clear contact links.
3. **Academic Evaluators & Researchers**: Reviewing the MS6033 dissertation research proposal (*"Representing the Spectrum"*), research methodology, and neurodiversity-inclusive game design frameworks.

## Product Purpose

Serve as the definitive digital portfolio and interactive showcase for Joshua Johnson, demonstrating uncompromised technical game design craft, playable prototypes, custom shaders, and academic research.

## Positioning

*"If I don't know it, I learn it; if I need it, I make it."*
A systems-first game designer who unites low-level engine engineering (Unreal Engine 5 C++, Niagara, HLSL) with visceral player feedback, tactile game feel, and academic rigor in cognitive accessibility.

## Operating Context

- **Harness & Deploy**: GitHub Pages (`https://joshuel2.github.io/PortfolioWebsite/`) running Vite, React 19, Tailwind CSS v4, Framer Motion, and Web Audio API.
- **Client Environments**: Chrome, Firefox, Safari across mobile (375px), tablet (768px), laptop (1280px), and ultrawide desktop (1920px).
- **Evaluation Rituals**: Portfolio reviews often occur on dual monitors, laptops during transit, or mobile devices in recruiter queues. Every second of friction, lag, or visual noise lowers conversion.

## Capabilities and Constraints

- **Playable Demos & Media**: Integrated YouTube showcases, interactive audio engine, downloadable dissertation documents (`.docx`, `.pptx`), and GitHub repository links.
- **Zero-Tolerance Boundaries**: Absolutely never mention poverty, financial hardship, or personal/family medical issues in copy or case studies. Focus exclusively on technical innovation, craftsmanship, and problem-solving.
- **Performance Budget**: Target <500 kB initial bundle size, zero layout shifts (CLS = 0), and 60 FPS transitions.
- **Full Accessibility**: Strict conformance with WCAG 2.1 AA, `prefers-reduced-motion` compliance, full keyboard navigation, and touch-target padding (min 44x44px).

## Brand Commitments

- **Tone**: Grounded, authoritative, technical, concise, authentic. Purge all corporate fluff and generic AI templates.
- **Palette & Mood**: Deep industrial graphite/slate canvas, sharp architectural contrast, deliberate telemetry/tactile accents.
- **Input Feel**: High responsiveness, physical button depression states, intentional procedural sound cues with mute persistence.

## Evidence on Hand

- **15 Documented Projects**: MS6032 Group Project (UE 5.8 stylized hybrid shooter), Procedural Dungeon Generator, VR Climbing Physics, HLSL Cel Shaders, Niagara VFX packs.
- **Academic Research**: MS6033 Dissertation Proposal (*"Representing the Spectrum"*), full proposal document, and presentation slide deck.
- **Code & Repositories**: Public and private GitHub repositories, C++ gameplay classes, and interactive Web Audio engine.

## Product Principles

1. **Visceral Game Feel**: The interface itself must feel like a game artifact—tactile, responsive, and diegetically grounded.
2. **Ruthless Hierarchy**: The work and technical evidence speak first; decorative chrome recedes.
3. **Zero AI Clichés**: Ban generic purple mesh gradients, glassmorphism cards, and centered hero-with-three-cards layouts.
4. **Universal Accessibility**: Every animation and sound must have a purpose and respect user sensory preferences.
